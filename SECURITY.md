# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| main    | ✅        |

## Reporting a Vulnerability

Please report security issues via GitHub Security Advisories or contact the maintainers
privately. Do not open public issues for undisclosed vulnerabilities.

## Best Practices

- Never commit `.env` or API keys
- Use `.env.example` as the template
- Rotate tokens used in connector workflows
- Follow SpaceX/Terrafab security-first CI/CD patterns in `standards/`
