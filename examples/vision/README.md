# Vision Customization

Use cases: image classification, object detection on Colossus.

- **Config:** `configs/vision.yaml`
- **Model:** `src/model.py`
- **Pipeline:** `pipeline.py`

## Quick Start

```bash
python examples/vision/pipeline.py --config examples/vision/configs/vision.yaml
```
