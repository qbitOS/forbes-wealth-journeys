Elon Musk / xAI Code Brand Guide (Official Standard)
Core Principle
"Delete everything that is not necessary. Make it so simple that it cannot be made simpler. Truth-seeking, mission-critical, zero bullshit."
1. Repository Presentation (README & Structure)

Title: One line, maximum signal.
Example: 🧠 Grok Assembly Line – Colossus/Dojo Template
Description: One sentence that tells a new user exactly what it does and why it matters for space-grade work.
First thing the user sees: A one-click "Quick Start" with a single command or button that pulls the exact folder.
No walls of text. Use headings, code blocks, Mermaid diagrams (gitgraph for flow), and tables only when they save time.
Always include:
SuperHeavyGrok credit (or equivalent contributor line).
Current LLM version (Grok 4.20 Heavy).
One-line "Why this exists" tied to space travel / understanding the universe.


2. Code Presentation (the SpaceX capsule standard)

Clean, minimal, readable at a glance.
JAX or Rust preferred for performance-critical systems (Colossus/Dojo).
Python only when necessary, with strict type hints, docstrings, and no magic.
File names: train.py, infer.py, capsule_ui.js — descriptive and short.
Comments: Only when they explain "why", never "what".
UI code (capsule touchscreens): Pristine JS/HTML/CSS. Real-time, high-contrast, dark theme, monospace where appropriate, no animations unless they serve function. Think Starship cockpit — functional first, beautiful second.
No unnecessary dependencies. Lock everything.
Every repo must be runnable with one command after clone.

3. Folder & Naming Standards

examples/spacex-capsule-ui/ (or equivalent) for mission-critical UI demos.
scripts/colossus-launch.sh for cluster jobs.
configs/ for everything configurable.
data/ with DVC.
No junk folders. Every directory must have a purpose and a README.md explaining it in one paragraph.

4. Pages / Frontend (Option 2 Configurator)

Dark theme, high-contrast green accents (Grok/xAI/SpaceX style).
Title: "Grok Assembly Line – Option 2 Configurator"
Heading: "Choose your template..."
One-click buttons that output a single copy-paste command for any AI.
Live ECharts heatmap for activity/metrics (no fluff charts).
Zero marketing copy. Pure utility.
